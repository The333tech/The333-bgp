# Security Policy

## Поддерживаемая версия

Сейчас поддерживается ветка **0.1.x**.

## Базовая модель безопасности

The333-BGP рассчитан на запуск в доверенной локальной сети рядом с MikroTik.

**Не открывай порты `8090`, `8088` и `179` напрямую в Интернет.**

Для доступа извне используй один из вариантов:

- VPN до локальной сети;
- reverse proxy с TLS;
- firewall allowlist по IP.

## Пароль портала

- Логин администратора: `admin`.
- Минимальная длина пароля: 8 символов.
- Новые установки хранят пароль как `WEB_PASSWORD_HASH`.
- Браузер не сохраняет пароль в `localStorage`; после перезагрузки вкладки нужно войти снова.
- Backend ограничивает количество неудачных попыток входа.

Смена пароля на VM:

```bash
cd /opt/the333-bgp
./scripts/the333bgp.sh set-password
```

## API

Управляющие API требуют авторизацию портала. Исключение — `/health`, который используется healthcheck'ом контейнера и не возвращает секреты.

## MikroTik

- Перед изменением BGP создай зашифрованный RouterOS backup и скачай его с устройства.
- Обеспечь независимый доступ через MAC WinBox, serial console или физический доступ.
- Не вставляй в Portal `/export show-sensitive`, AWG private keys, preshared keys и пароли.
- Помощник сначала создаёт выключенное BGP connection с quarantine filter. Активация выполняется отдельным этапом после проверки.
- Не применяй RouterOS 7 команды к RouterOS 6.
- Не загружай container image по mutable-тегу `latest` без проверки конкретного release и SHA-256/digest.

## Обновления

Обновления запускаются через отдельный контейнер `the333-host-updater`. Его API не публикуется на порту хоста и требует отдельный случайный token. Контейнер имеет доступ к Docker socket, поэтому token из `.env` нужно защищать как административный секрет.

Перед заменой файлов создаётся резервная копия. После перезапуска проверяется готовность backend, GoBGP и портала; при ошибке обновлятор автоматически возвращает файлы предыдущей версии.

Если в release manifest указан `sha256`, архив проверяется до распаковки. Не меняй manifest URL на неизвестный источник.

## Сообщить о проблеме

Если нашёл проблему безопасности, создай issue в GitHub-репозитории проекта.

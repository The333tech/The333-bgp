# Security Policy

## Поддерживаемая версия

Сейчас поддерживается ветка **0.1.x**.

## Базовая модель безопасности

The333-BGP рассчитан на запуск в доверенной локальной сети рядом с MikroTik.

**Не открывай порты `8090`, `8088` и `179` напрямую в Интернет.**

Для доступа извне используй один из вариантов:

- VPN до локальной сети;
- reverse proxy с TLS;
- firewall allowlist по IP.

## Пароль портала

- Логин администратора: `admin`.
- Минимальная длина пароля: 8 символов.
- Новые установки хранят пароль как `WEB_PASSWORD_HASH`.
- Backend ограничивает количество неудачных попыток входа.

Смена пароля на VM:

```bash
cd /opt/the333-bgp
./scripts/the333bgp.sh set-password
```

## API

Управляющие API требуют авторизацию портала. Исключение — `/health`, который используется healthcheck'ом контейнера и не возвращает секреты.

## Обновления

Обновления запускаются через отдельный контейнер `the333-host-updater`. Перед заменой файлов создаётся резервная копия, пользовательские данные сохраняются.

## Сообщить о проблеме

Если нашёл проблему безопасности, создай issue в GitHub-репозитории проекта.

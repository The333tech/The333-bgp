# Security Policy

## Поддерживаемая версия

Сейчас поддерживается ветка **0.1.x**.

## Базовая модель безопасности

The333-BGP рассчитан на запуск в доверенной локальной сети рядом с MikroTik.

**Не публикуй порты `8090`, `8088` и `179` напрямую в Интернет.**

Для доступа извне используй:

- VPN до локальной сети;
- reverse proxy с TLS и дополнительной авторизацией;
- firewall allowlist по IP.

## Секреты

- `.env` содержит пароль портала и локальные параметры сети.
- `.env` не должен попадать в GitHub.
- Установщик ставит права `600` на `.env`.
- Перед публикацией релиза проверь, что в архив не попали `data/`, `backups/`, логи и локальные JSON-дампы.

## Обновления

Обновление из портала по умолчанию отключено:

```env
PRODUCT_UPDATE_ENABLED=false
```

Это сделано специально. Backend-контейнер не должен получать прямой доступ к Docker-хосту. Для production-обновлений нужен отдельный host-updater слой с ограниченной командой, проверкой версии и обязательным `sha256` в manifest.

## API

Все управляющие API должны требовать авторизацию. Исключение допускается только для `/health`, который используется healthcheck'ом контейнера и не должен возвращать секреты.

## Сообщить о проблеме

До публичного релиза сообщай проблемы безопасности напрямую владельцу проекта. Не публикуй секреты, `.env`, дампы маршрутов с внутренними IP и логи с паролями в issue.

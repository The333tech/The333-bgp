# Production checklist The333-BGP

Перед публикацией релиза:

## Репозиторий

- [ ] В репозитории нет `.env`, `data/`, `backups/`, логов и временных JSON-дампов.
- [ ] `README.md` содержит быстрый старт и ссылку на полную инструкцию.
- [ ] `docs/INSTALL.md` проверен на чистой VM.
- [ ] `SECURITY.md` лежит в корне проекта.
- [ ] Версия в `VERSION`, `.env.example`, backend и portal совпадает.

## Установщик

- [ ] `install.sh` запускается на чистой Ubuntu VM.
- [ ] `install.sh` запускается на чистой Debian VM или корректно сообщает, что ОС не поддерживается.
- [ ] Повторный запуск на установленной системе предлагает `update`, `backup`, `status`, `quit`.
- [ ] IP, ASN и порты валидируются до записи `.env`.
- [ ] `.env` получает права `600`.

## Обновления

- [ ] `update-manifest.json` содержит актуальную stable-версию.
- [ ] Для каждого release archive заполнен `sha256`.
- [ ] `scripts/the333bgp.sh check-update` показывает корректную версию.
- [ ] `scripts/the333bgp.sh update --dry-run` не меняет файлы.
- [ ] `scripts/the333bgp.sh update` создаёт backup до замены файлов.
- [ ] Пользовательские данные в `data/` сохраняются.

## Безопасность

- [ ] Порты `8090`, `8088`, `179` не открыты в Интернет без VPN/firewall/reverse proxy.
- [ ] Все управляющие API требуют авторизацию.
- [ ] `/health` не раскрывает секреты.
- [ ] В Docker Compose нет `privileged: true`, mount Docker socket и лишних capabilities.
- [ ] Backend не выполняет произвольные shell-команды из пользовательского ввода.
- [ ] Пароль портала не логируется.

## BGP

- [ ] GoBGP поднимается отдельно от backend/portal.
- [ ] Перезапуск backend/portal не пересоздаёт GoBGP core.
- [ ] Last-good маршруты сохраняются после рестарта.
- [ ] MikroTik получает ожидаемое количество маршрутов.
- [ ] Community-профили документированы в портале.

## UI

- [ ] Портал открывается на desktop и mobile.
- [ ] Страницы `Дашборд`, `Источники маршрутов`, `Сервисные модули`, `Маршруты`, `Подключения`, `Комьюнити`, `Обновления`, `Для MikroTik` проверены.
- [ ] Скролл страниц плавный.
- [ ] Модальные окна не выходят за экран.
- [ ] Длинные URL/CIDR/имена файлов прокручиваются или компактно переносятся.
